# BOCH-NEXO-MX

Sistema integral para México: terminal web, IA Llama, APIs cripto (CoinGecko, CryptoMarket, Etherscan, Mempool), wallet descentralizado, Termux y entorno ISH Alpine Linux.

## Descripción

BOCH-NEXO-MX es una suite modular diseñada para reunir:

- Terminal web para operación y control
- Inteligencia artificial con Llama
- Integración con fuentes de datos crypto
- Wallet descentralizado y gestión segura
- Entorno Linux móvil para automatización
- Infraestructura preparada para dashboards y workflows

## Objetivo

Crear un ecosistema funcional y extensible para operaciones cripto, análisis de mercado y automatización inteligente con un enfoque moderno y escalable.

## Ejecución local

1. Clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta un servidor local:

```bash
python3 -m http.server 8000
```

4. Abre en tu navegador:

```text
http://localhost:8000
```

## Archivos principales

- `index.html` – landing page principal
- `styles.css` – estilos visuales y responsive
- `script.js` – interactividad con selector de precios y años
