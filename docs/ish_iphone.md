# Instalación en ISH para iPhone\n\n## ¿Qué es ISH?\n\nISH es un emulador de terminal Linux que funciona en iOS. Permite ejecutar comandos de Linux directamente en tu iPhone sin jailbreak.\n\n**Requisitos:**\n- iPhone con iOS 13+\n- App ISH instalada desde App Store\n- ~500MB de espacio disponible\n- Conexión a internet\n\n## Paso 1: Instalar ISH\n\n1. Abre App Store en tu iPhone\n2. Busca \"iSH\"\n3. Instala la app oficial de iSH\n4. Abre ISH después de instalar\n\n## Paso 2: Actualizar paquetes\n\nUna vez dentro de ISH, ejecuta:\n\n```bash\napk update\napk upgrade\n```\n\nEsto puede tomar 2-5 minutos dependiendo de tu conexión.\n\n## Paso 3: Instalar Python y Git\n\n```bash\napk add python3 py3-pip git curl\n```\n\nEspera a que termine. Esto instala:\n- Python 3.x\n- pip (gestor de paquetes)\n- git (control de versiones)\n- curl (para descargas)\n\n## Paso 4: Clonar el repositorio\n\n```bash\ncd ~\ngit clone https://github.com/quieresakarla1216-crypto/BOCH-NEXO-MX.git\ncd BOCH-NEXO-MX\n```\n\n## Paso 5: Crear entorno virtual\n\n```bash\npython3 -m venv .venv\nsource .venv/bin/activate\n```\n\nDeberías ver `(.venv)` al inicio de tu línea de comando.\n\n## Paso 6: Instalar dependencias\n\n```bash\npip install --upgrade pip\npip install -r requirements.txt\n```\n\nEsto puede tomar 5-10 minutos. Ten paciencia.\n\n## Paso 7: Ejecutar el sistema\n\n### Opción A: Terminal principal\n\n```bash\npython main.py\n```\n\nVerás el prompt de BOCH-NEXO-MX:\n```\nBOCH-NEXO-MX\nSistema de apoyo, seguridad, IA y automatización\nboch>\n```\n\n### Opción B: Terminal web\n\nEn otra ventana de ISH (o nueva pestaña):\n\n```bash\ncd BOCH-NEXO-MX/web\npython app.py\n```\n\nLuego:\n1. Abre Safari en tu iPhone\n2. Ve a `http://localhost:8000`\n3. Verás la terminal web profesional\n\n## Comandos útiles en ISH\n\n```bash\n# Ver carpeta actual\npwd\n\n# Listar archivos\nls -la\n\n# Navegar\ncd carpeta/\n\n# Volver atrás\ncd ..\n\n# Ver contenido de archivo\ncat archivo.txt\n\n# Editar archivo (presiona ESC luego :wq para guardar)\nvi archivo.txt\n\n# Salir del entorno virtual\ndeactivate\n\n# Limpiar pantalla\nclear\n```\n\n## Configuración recomendada\n\n### Crear archivo .env\n\n```bash\ncd ~/BOCH-NEXO-MX\ncp config/.env.example config/.env\n```\n\nLuego edita el archivo:\n\n```bash\nvi config/.env\n```\n\nAgrega tus APIs (opcional por ahora):\n```\nCOINGECKO_API_KEY=tu_clave_aqui\nETHERSCAN_API_KEY=tu_clave_aqui\nPYTHON_ENV=development\n```\n\n## Seguridad en ISH\n\n### iCloud Drive (Sincronización segura)\n\nPara sincronizar archivos con iCloud Drive de forma segura:\n\n```bash\n# Habilitar acceso a iCloud\n# Esto debe hacerse a través de la app Files en iOS\n```\n\n1. Abre la app Files en iOS\n2. Toca Editar en la esquina superior derecha\n3. Activa \"iCloud Drive\"\n4. En ISH, tus archivos estarán en `/private/var/mobile/Library/Mobile Documents`\n\n### Mantener seguridad\n\n- Usa PIN en tu iPhone para proteger el acceso\n- No compartas tus claves API\n- Mantén ISH actualizado\n- Usa modo offline para operaciones sensibles\n\n## Solución de problemas\n\n### ISH se cierra de repente\n\n- Es normal, ISH tiene limitaciones de memoria en iOS\n- Reinicia ISH y ejecuta nuevamente\n- Cierra otras apps para liberar memoria\n\n### Error: \"command not found\"\n\nProbablemente no instalaste bien. Intenta:\n\n```bash\napk add --no-cache python3 py3-pip git curl\n```\n\n### Error: \"Permission denied\"\n\nIntenta dar permisos:\n\n```bash\nchmod +x archivo.py\n```\n\n### ISH va muy lento\n\n- Cierra otras apps en iOS\n- Reinicia tu iPhone\n- ISH es más lento que una computadora, es normal\n\n### No puedo acceder a archivos de iCloud\n\n- ISH tiene acceso limitado a iCloud por seguridad de iOS\n- Usa `cp` para copiar archivos manualmente si es necesario\n\n## Uso recomendado en iPhone\n\n### Para desarrollo\n\n1. Abre ISH\n2. Ejecuta `cd ~/BOCH-NEXO-MX`\n3. Prueba comandos y scripts\n4. Usa git para versionar cambios\n\n### Para monitoreo\n\n1. Abre la terminal web en Safari\n2. Ejecuta consultas de API\n3. Revisa estado del sistema\n4. Monitorea wallets\n\n### Para seguridad\n\n1. Usa ISH en modo offline\n2. Genera semillas localmente sin internet\n3. Usa cifrado para datos sensibles\n4. Guarda backups en iCloud Drive\n\n## Avanzado: Automatización\n\nPara ejecutar scripts automáticamente cada cierto tiempo:\n\n```bash\n# Instalar crond (demonio de cron)\napk add dcron\n\n# Editar crontab\ncrontab -e\n\n# Agregar tarea (ejemplo: cada 30 minutos)\n*/30 * * * * cd ~/BOCH-NEXO-MX && python -m wallet.sync\n```\n\n## Conexión con Bitso (México)\n\nSi quieres integrar Bitso API:\n\n```bash\npip install bitso-v3\n```\n\nLuego en tu código:\n\n```python\nfrom bitso_v3 import bitso\napi = bitso.bitso(key, secret)\n```\n\n## Próximos pasos\n\n1. **Crear wallet:** `python -m wallet.manager`\n2. **Sincronizar:** `python -m wallet.sync`\n3. **Revisar ledger:** `python -m wallet.ledger`\n4. **Usar IA:** `python main.py` y escribe comandos\n5. **Terminal web:** `cd web && python app.py`\n\n## Notas finales\n\n- ISH es perfecto para desarrollo y pruebas\n- No es recomendado para operaciones de producción sensibles\n- Usa testnet para pruebas financieras\n- Mantén respaldos seguros\n- Aprende Python y Linux mientras usas ISH\n\n---\n\n**BOCH-NEXO-MX en tu iPhone**\n\nCon ISH, ahora tienes un sistema Linux completo en tu bolsillo.\nÚsalo sabiamente, con seguridad y responsabilidad.\n\n✓ Legal\n✓ Seguro\n✓ Modular\n✓ Responsable\n"
